🎯 RÉSOLUTION DES PROBLÈMES

❌ PROBLÈME 1 : Vidéo ne s'affiche pas
✅ SOLUTION : 
  - Vérifier que videoId est bien extrait (Support.videoId en BD)
  - Vérifier que support.type === "VIDEO"
  - Vérifier que support.url contient un lien YouTube valide

  Debug : Ajouter console.log(support.videoId) dans YouTubePlayer


❌ PROBLÈME 2 : Progression perdue (25-50-75-100%)
✅ SOLUTION :
  - Vérifier que reportedEvents.current[] se remplit
  - Vérifier que events JSON est bien stocké en BD
  - Vérifier que progression AUGMENTE (jamais diminue)

  Debug : Voir VideoProgress.events dans la BD


❌ PROBLÈME 3 : Position ne reprend pas
✅ SOLUTION :
  - Vérifier que lastPosition est sauvegardé en BD
  - Vérifier que seekTo() est appelé après ready
  - Vérifier que pauseVideo() suit le seekTo

  Debug : 
    console.log("lastPosition:", lastPositionRef.current)
    console.log("Player duration:", player.getDuration())


❌ PROBLÈME 4 : Vidéo s'arrête/bug en cours de lecture
✅ SOLUTION :
  - L'intervalle de tracking toutes les 10s est normal
  - Si vraiment des freezes : diminuer l'intervalle à 5000ms
  - Vérifier que le réseau répond bien aux POST /api/video/progress

  Debug : Voir l'onglet Network dans DevTools

🔧 CONFIGURATION OPTIONNELLE

Pour augmenter la fréquence de sauvegarde :
  Changer dans YouTubePlayer.jsx :
  intervalRef.current = setInterval(() => trackProgress(false), 10000);
  
  À :
  intervalRef.current = setInterval(() => trackProgress(false), 5000);


Pour marquer auto-complété à 80% au lieu de 90% :
  Changer dans /api/video/progress.js :
  const completed = newProgression >= 90 || newEvents.includes(100);
  
  À :
  const completed = newProgression >= 80 || newEvents.includes(100);
